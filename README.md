# GIF Play Pause Accessibility 🎬♿

A simple project to make **GIFs accessible** with **Play/Pause controls**.  
Animated GIFs can distract or harm users with motion sensitivity. This solution adds **accessible controls** so users can start, stop, or pause GIFs anytime — improving compliance with **WCAG accessibility guidelines**.

---

## ✨ Features

- Play and Pause button for animated GIFs.
- Keyboard accessible controls.
- Screen reader friendly with ARIA labels.
- Follows **WCAG 2.2.2 Pause, Stop, Hide**.
- Easy to use in any website or project.

## 🛠️ How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/Prik03/Gif-Play-Pause.git
   ```
2. Open index.html in your browser.

3. Click Play to start the GIF, Pause to stop it.
